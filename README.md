# Cosom PWA

PWA synchronisée pour la ligue du lundi.

Commence par **SETUP-FIREBASE.md** ou double-clique **DEPLOYER.bat** après avoir créé le projet Firebase et activé Google + Email/Password dans Authentication, puis Firestore.

Fonctions incluses : comptes privés, invitation par code, joueurs/gardiens/remplaçants, calendrier automatique des lundis, confirmations de présence et absences planifiées d'avance, équipes Foncés/Pâles, chrono synchronisé, alarme sur un seul appareil, buts et jusqu'à deux passes, périodes configurables, historique/statistiques/absences, export JSON et installation Android/iPhone.
